## The entry

> **sockwidow — the lone sock left behind when its partner vanishes in the wash.**

One invented English word, defined in a single clear line (76 characters).

Every household knows the lone sock, but English has no word for it — *sockwidow* fills that gap. It is sayable, spellable and memorable, built the way English grows words (sock + widow).
